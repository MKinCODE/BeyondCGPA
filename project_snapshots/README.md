# Project Snapshots Guide for Hackathon Judges

To give hackathon judges the most compelling visual overview of BeyondCGPA, capture these **4 core screenshots** and save them in this directory with the exact filenames below:

---

### The 4 Key Snapshots:

| Target Filename | What to Capture in the UI | Key Features Showcased |
| :--- | :--- | :--- |
| **`01_dashboard_command_center.png`** | Student Command Center (`/dashboard`) | Today's Focus card, readiness horizon pill (~X months), pacing status badge (`OnPace`), weekly velocity, and industry topic preview. |
| **`02_ai_career_mentor.png`** | AI Career Mentor chat stream (`/dashboard/mentor`) | Real-time chat showing workload reasoning ("It's too fast for me"), live student telemetry context pill on the left, and follow-up suggestion chips. |
| **`03_adaptive_roadmap.png`** | Adaptive Roadmap page (`/dashboard/preparation`) | Sequenced roadmap phases (DSA, Development, System Design), allocated learning units, completed vs remaining units, and progress sliders. |
| **`04_opportunities_match.png`** | Verified Opportunities feed (`/dashboard/opportunities`) | Job & internship cards with dynamic CIE match scores (e.g. 92% match), verified skills highlighted, and skill gap analysis. |

---

### Tips for Best Quality:
- **Aspect Ratio:** 16:9 or full-browser window (e.g., 1920x1080 or 1440x900).
- **Format:** PNG or WebP recommended for crisp typography and UI borders.
- As soon as you save an image here with its filename (e.g. `01_dashboard_command_center.png`), it will immediately display in the root [`README.md`](../README.md)!
